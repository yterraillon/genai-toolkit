# Plugins

## Dotnet-test

### Installation

Permet la mise en place et l'update des TUs sur une solution, via plusieurs sub-agents
[source](https://github.com/dotnet/skills/tree/main/plugins/dotnet-test)

```
/plugin marketplace add dotnet/skills
/plugin install dotnet-test@dotnet-agent-skills
```

### Usage : 

`/dotnet-test:code-testing-agent`
